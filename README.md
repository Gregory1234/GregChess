# GregChess
A Bukkit plugin adding chess to minecraft written in Kotlin.

Works in Minecraft `1.21.10`.

## Gradle tasks
### Build
- Bukkit plugin jar: `:gregchess-bukkit:finalJar`

(All jars are moved to `build/libs`)

### Run
- Paper server with the plugin: `:gregchess-bukkit:runServer`

### Documentation
- Dokka html: `:dokkaGenerateHtml`
